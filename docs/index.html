features

privacy-first

SSN and bank info stay local in .env files. Sensitive data never touches the AI.

ai-powered

Specialist agents handle income processing, deduction analysis, credit evaluation.

52-irs-forms

Form 1040, all schedules, and common credit forms. Generate filing-ready PDFs.

pub-17-indexed

Complete IRS Publication 17 converted to searchable markdown.

deterministic-math

Tax brackets and credits calculated by scripts—not hallucinating AI.

open-source

Review every calculation. Verify against IRS publications before filing.

quick-start
# install opencode
curl -fsSL https://opencode.ai/install | bash

# clone your private fork
git clone https://github.com/dakdevs/opencode-taxes.git
cd opencode-taxes

# set up sensitive data (never sent to AI)
cp .env.example .env

# start opencode and run the workflow
opencode
