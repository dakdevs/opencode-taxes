# Tax Scripts

Bun scripts for tax calculations and PDF generation.

## PDF Generation

Generate the final filing-ready PDF packet:

```bash
bun scripts/generate-pdf-packet.ts
```

This script:
1. Reads JSON form data from `output/` (generated by /tax-prep workflow)
2. Reads sensitive data from `.env` (SSN, bank info)
3. Fills IRS PDF forms using pdftk
4. Merges all forms into `output/tax-return-packet.pdf`

**Requirements:**
- pdftk (`brew install pdftk-java` on macOS)
- `.env` file with sensitive data filled in
- Completed `/tax-prep` workflow with JSON files in `output/`

**Security:** Your sensitive data is read locally and written directly to PDFs. The AI never sees SSNs, bank account numbers, or IP PINs.

## Calculation Scripts

Used by agents for deterministic tax calculations. All output JSON.

### Tax Brackets
```bash
bun scripts/tax-brackets.ts <taxable_income> <filing_status>
```
Output: `{"tax":X,"effectiveRate":X,"marginalRate":X}`

### Standard Deduction
```bash
bun scripts/standard-deduction.ts <filing_status> [age] [is_blind]
```
Output: `{"base":X,"additional":X,"total":X}`

### Capital Gains & NIIT
```bash
bun scripts/capital-gains.ts <taxable_income> <ltcg> <filing_status> [magi]
```
Output: `{"atZero":X,"atFifteen":X,"atTwenty":X,"ltcgTax":X,"niit":X,"total":X}`

### Self-Employment Tax
```bash
bun scripts/se-tax.ts <net_profit> <filing_status> [wages_subject_to_ss]
```
Output: `{"seBase":X,"ssTax":X,"medicareTax":X,"additionalMedicare":X,"totalSETax":X,"seDeduction":X}`

### Credits
```bash
bun scripts/credits.ts ctc <agi> <filing_status> <qualifying_children>
bun scripts/credits.ts eic <agi> <filing_status> <qualifying_children> <earned_income>
bun scripts/credits.ts education <agi> <filing_status> <aotc|llc> <expenses>
bun scripts/credits.ts saver <agi> <filing_status> <contributions>
```

## Filing Statuses

- `single`
- `married_joint`
- `married_separate`
- `head_of_household`
- `qualifying_surviving_spouse`
