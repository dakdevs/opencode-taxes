# 1099-R (Retirement Distributions)

Place your 1099-R forms here.

## What Is a 1099-R?

Financial institutions send 1099-R when you receive distributions from:
- IRAs (Traditional, Roth, SEP, SIMPLE)
- 401(k), 403(b), 457 plans
- Pensions
- Annuities

## What to Look For

| Box | Description | Notes |
|-----|-------------|-------|
| 1 | Gross distribution | Total amount distributed |
| 2a | Taxable amount | Amount subject to tax |
| 2b | Taxable amount not determined | You may need to calculate |
| 4 | Federal tax withheld | Credit on return |
| 7 | Distribution code | Determines tax treatment |

## Important Distribution Codes (Box 7)

| Code | Meaning | 10% Penalty? |
|------|---------|--------------|
| 1 | Early distribution, no exception | YES |
| 2 | Early distribution, exception applies | NO |
| 3 | Disability | NO |
| 4 | Death | NO |
| 7 | Normal distribution (age 59½+) | NO |
| G | Direct rollover | Not taxable |
| H | Direct rollover from Roth | Not taxable |

## Roth IRA Distributions

Qualified Roth distributions are tax-free. Nonqualified distributions may have taxable earnings.

## Rollovers

If you rolled over to another retirement account within 60 days:
- Report the distribution
- Report the rollover
- Net tax = $0 (if full rollover)
