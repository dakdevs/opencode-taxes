# Tax Calculation Worksheets

This directory contains calculation worksheets and reference tables for preparing your 2025 federal tax return.

## Contents

| File | Description |
|------|-------------|
| `tax-brackets-2025.md` | Federal income tax brackets and rates |
| `standard-deduction-2025.md` | Standard deduction amounts by filing status |
| `capital-gains-rates.md` | Long-term capital gains tax rates |
| `self-employment-tax.md` | SE tax calculation worksheet |
| `child-tax-credit.md` | Child tax credit calculation and phase-outs |
| `earned-income-credit.md` | EIC tables and eligibility |
| `ira-contribution-limits.md` | IRA/401k contribution limits and phase-outs |
| `amt-worksheet.md` | Alternative Minimum Tax calculation |
| `qbi-deduction.md` | Qualified Business Income deduction (Section 199A) |
| `education-credits.md` | AOTC and LLC calculations |

## How to Use

1. Reference these worksheets when calculating specific tax items
2. Use the formulas to compute your tax liability
3. Cross-reference with IRS instructions for edge cases

## Tax Year

All figures are for **Tax Year 2025** (returns filed in 2026).
