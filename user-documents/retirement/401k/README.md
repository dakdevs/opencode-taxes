# 401(k) and Employer Plan Statements

Place your 401(k), 403(b), or other employer plan statements here.

## What to Include

- Year-end account statement
- Summary of contributions
- Employer match information

## Where to Find Contribution Information

Your 401(k) contributions appear on your **W-2**:
- **Box 12, Code D** - 401(k) elective deferrals
- **Box 12, Code E** - 403(b) elective deferrals
- **Box 12, Code G** - 457(b) elective deferrals
- **Box 12, Code AA** - Roth 401(k) contributions
- **Box 12, Code BB** - Roth 403(b) contributions

## 2025 Contribution Limits

| Age at Year End | Contribution Limit |
|-----------------|-------------------|
| Under 50 | $23,500 |
| 50-59 | $31,000 |
| 60-63 | $34,750 |
| 64 and older | $31,000 |

## Traditional vs. Roth 401(k)

| Traditional | Roth |
|-------------|------|
| Pre-tax contributions | After-tax contributions |
| Reduces current taxable income | No current tax benefit |
| Taxed on withdrawal | Tax-free withdrawal |
| W-2 Box 12, Code D | W-2 Box 12, Code AA |

## Employer Match

Employer matching contributions are always pre-tax (even if you contribute to Roth).

Employer match does NOT count toward your contribution limit.

## Why Keep Statements?

- Verify contributions match W-2
- Track Roth vs. Traditional allocations
- Document for Saver's Credit calculation
- Basis tracking for Roth accounts
