# 1099-MISC (Miscellaneous Information)

Place your 1099-MISC forms here.

## What Is a 1099-MISC?

Various payers send 1099-MISC for miscellaneous income types.

## Common Types of Income

| Box | Description | Tax Treatment |
|-----|-------------|---------------|
| 1 | Rents | Rental income (Schedule E) |
| 2 | Royalties | Royalty income (Schedule E) |
| 3 | Other income | Prizes, awards, etc. |
| 4 | Federal tax withheld | Credit on return |
| 5 | Fishing boat proceeds | Special rules apply |
| 6 | Medical/healthcare payments | If you're a provider |
| 10 | Crop insurance proceeds | Farm income |

## Common Scenarios

**Rent payments:** If you're a landlord and received rent from a business.

**Royalties:** If you received royalties from oil/gas, patents, copyrights.

**Prizes/Awards:** Lottery winnings, contest prizes, etc.

## Note on Box 7

Box 7 (Nonemployee compensation) is now reported on **1099-NEC**, not 1099-MISC.
