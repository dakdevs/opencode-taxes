# Tax Credits Documentation

Place documents for tax credits in the appropriate subfolders.

## Credits vs. Deductions

**Credits** are better than deductions!
- Deductions reduce your taxable income
- Credits reduce your tax dollar-for-dollar

## Types of Credits

| Type | Effect |
|------|--------|
| **Nonrefundable** | Reduces tax to $0, no refund from excess |
| **Refundable** | Can result in refund even if you owe no tax |
| **Partially refundable** | Some portion is refundable |
